# Provenance: how the per-class description sets were written

**Disclosure for the paper.** Six of the seven description sets in `examples/*_descriptions.py` were written by
an LLM coding agent, the research session. The seventh, Banking77, was also written in an agent session of the
study. None was generated by a script from data, and none was ever revised after it was first committed.

## How they were written

**No separate generation prompt was used.** The agent wrote each set directly, in the course of its task. Below
are the instructions it was working under, quoted or summarised from the task record.

- **SNIPS and CLINC150** (2026-09-29). Written to test whether per-class descriptions, the lever used by the
  description-based "dataless" zero-shot baseline, help the ensemble. The working instruction was one
  plain-language, disambiguating description per class, written from the label names. The CLINC150 experiment
  file states: "One disambiguating description per CLINC150 intent."
- **HWU64, MASSIVE, MTOP and Bitext** (2026-10-04). The instruction relayed from the project owner was:
  > "author generic one-line descriptions … plain rephrasings of each label name. Nothing taken from the data,
  > no test-set peeking."
- **Banking77** (2026-09-22). The commit describes the text as hand-authored, that is, written directly rather
  than produced by a script. The commit message says the descriptions were "grounded in the ACTUAL HF label
  names" and "written to separate near-duplicate intents", for example `card_arrival` vs
  `card_delivery_estimate`, and the `top_up_*` and `verify_*_identity` families.

## What was visible to the author

- **Label names.** For every set, only the label strings returned by the dataset loader. No train or test
  utterances were consulted while writing.
- **Aggregate test accuracies.** These were already known for every set:
  - for the six non-Banking77 sets, names-only zero-shot full-test results were committed on 2026-09-29 at
    01:09 +08:00, before any of their descriptions;
  - for Banking77, full-test zero-shot accuracies with bare label names existed before 2026-09-22.

  These are aggregate numbers only.
- **Per-class errors.** No per-class test confusion analysis appears in the record before any set was written.
  For the six sets written by the research session, none was consulted. For Banking77, whether the authoring
  session looked at individual test errors is **unknown**.

## After writing

- **No revisions.** No set was edited after its first commit.
- **Measurement.** Each set was measured once on its full test set and reported as measured.
- **Where descriptions helped.** They helped on all seven datasets (see `results/*_descriptions.json`).
  Because no set was revised, the numbers are not the product of tuning the text on test results.
